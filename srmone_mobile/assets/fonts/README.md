# Fonts

The same three families the web app loads from Google Fonts, bundled so the
app never fetches fonts at runtime. Latin subsets from Fontsource
(https://fontsource.org), all under the SIL Open Font License 1.1.

- Inter (body text) 400–900
- Space Grotesk (display headings) 500, 700
- JetBrains Mono (course codes) 500, 700
